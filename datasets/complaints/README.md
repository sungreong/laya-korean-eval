# 계층형 민원 분류 진단

작성자가 만든 가상 데이터이며 실제 개인의 민원 기록이나 공식 지자체 분류표가 아니다. 고객 상담 요약을 입력받아 대→중→소 경로를 반환하는 업무를 모사한다.

| 대분류 | 중분류 3개 | 소분류 수 |
|---|---|---:|
| 생활환경 | 청소·폐기물, 소음·악취, 공원·녹지 | 각각 3개, 총 9개 |
| 도로·교통 | 주정차, 도로시설, 대중교통 | 각각 3개, 총 9개 |
| 행정·복지 | 민원행정, 복지지원, 공공시설 | 각각 3개, 총 9개 |

전체 정의는 `taxonomy.json`, 독립 시험 입력과 정답은 `cases.json`에 있다. `research/prepare_complaints.py`로 재생성할 수 있다.

| 대분류 | 중분류 | 소분류 3개 |
|---|---|---|
| 생활환경 | 청소·폐기물 | 생활쓰레기 수거 / 불법투기 / 대형폐기물 배출 |
| 생활환경 | 소음·악취 | 공사장 소음 / 영업장 소음 / 악취 |
| 생활환경 | 공원·녹지 | 수목 관리 / 공원시설 파손 / 공원 청결 |
| 도로·교통 | 주정차 | 불법주정차 / 주차시설 이용 / 견인·과태료 이의 |
| 도로·교통 | 도로시설 | 노면·보도 파손 / 가로등 고장 / 도로 배수 |
| 도로·교통 | 대중교통 | 버스 운행 / 정류장 시설 / 운수종사자 응대 |
| 행정·복지 | 민원행정 | 증명서 발급 / 온라인 민원 장애 / 처리 지연·공무원 응대 |
| 행정·복지 | 복지지원 | 지원 자격 / 지급 누락·지연 / 신청·제출 서류 |
| 행정·복지 | 공공시설 | 이용 예약 / 시설 고장 / 운영·이용 불편 |

- 81개: 소분류마다 직접 표현, 간접 표현, 여러 문제 중 현재 요청을 구별하는 복합 맥락 각 1개. 단일 경로 정답이 있다.
- 9개: 요약에 정보가 부족하여 여러 경로가 가능하다. `expected_leaf: null`, `acceptable_leaves`, `clarification_needed`를 기록했다. 이 사례는 단일 정답 정확도의 분모에서 제외한다.
- 콜센터/인터넷 상담 각 45개. 모두 한국어 요약 텍스트이며 음성 인식 품질은 시험하지 않는다.
- 학습용이 아닌 진단용이다. 이 90개에 학습하고 같은 90개 성능을 일반화 성능으로 보고해서는 안 된다.

## 비교 방식

`flat27`: 27개 소분류 설명을 한 입력에 넣고 하나를 선택한 뒤 부모 경로를 붙인다.

`cascade`: 대분류 3개 중 선택 → 예측한 대분류 아래 중분류 3개 중 선택 → 예측한 중분류 아래 소분류 3개 중 선택. 정답 부모를 주지 않으며 상위 오류는 하위로 전파된다.

두 방식 모두 유효한 경로만 출력하도록 코드가 구성되어 있다. 경로 일관성은 구조로 보장한 것이며 모델이 계층 규칙을 학습했다는 증거가 아니다. 단계별 confidence는 서로 다른 후보 집합의 값이므로 flat confidence와 직접 비교하지 않는다.

각 단계 정확도는 대분류, 대+중 경로, 대+중+소 전체 경로가 정답과 일치하는 비율이다. 최초 오류 단계와 난이도별 결과도 기록한다. 애매한 9개는 허용 경로 적중 수만 별도로 기록하며, 적중해도 실제 상담에서는 추가 확인이 필요하다. 모델은 평가에서 강제로 하나를 선택하므로 자동 보류·재질문 능력을 검증하지 않는다.

27개 후보 설명이 기본 head 예산에서 잘리는 문제를 피하려고 두 방식 모두 `max_len=2048`, `head_max_len=1536`을 사용한다. upstream의 후보당 48-token 제한을 검사하고 전체 출력 후보 수와 잘림 정보를 기록한다.

기존 `results/complaints-2026-10-07/trained/` 모델은 **영화 리뷰 감정 분류로 학습한 모델**이다. 민원 학습 모델로 오해하면 안 된다. 이를 기본 모델과 비교할 경우에는 다른 업무에 미친 영향을 보는 회귀 검사다.

## 민원 도메인 학습 자료

`training/train.jsonl` 729개와 `training/validation.jsonl` 243개는 27개 소분류가 같은 수로 들어간 합성 자료다. 학습은 소분류마다 27개, validation은 소분류마다 9개다. 상담 기록, 인터넷 민원, 짧은 메모, 긴 맥락, 간접 요청, 해결된 과거 문제, 한영 혼합, 모바일 축약, 복합 이슈를 포함한다. 생성 정보와 해시는 `training/manifest.json`에 있다.

```bash
python research/prepare_complaint_training.py
```

학습/validation/90개 시험셋 사이의 완전 동일 문장은 없다. 그러나 같은 작성자가 만든 템플릿 자료여서 표현과 라벨 어휘가 의미상 겹칠 수 있다. 독립 검수가 없는 편의 표본이므로 결과를 운영 환경의 정확도로 해석하지 않는다.
