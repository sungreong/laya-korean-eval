# 민원 27개 유형 추가 학습 사전 계획 (2026-10-07)

- 목표: 같은 3×3×3 민원 체계에서 유형별 학습 자료를 추가하면 기존의 학습 없는 성능보다 개선되는지 확인한다.
- 학습 729개(유형당 27), 검증 243개(유형당 9)를 작성자 정의 상황 문구와 서로 다른 문장 틀로 생성한다. 모든 유형은 균형이다.
- 표현 다양성은 정식 인터넷 민원, 콜센터 녹취체, 짧은 메모, 긴 배경 설명, 간접 요구, 해결된 과거 문제, 여러 이슈 중 우선순위, 한국어·영어 혼합, 모바일식 축약을 포함한다. 검증 문장 틀 9개는 학습 문장 틀 27개와 분리한다.
- 각 소분류에는 기존 시험 문장에 없던 상황 표현을 추가한다. 이는 새로운 **표현·상황**이며 새로운 라벨을 뜻하지 않는다. 운영 taxonomy 밖의 새 라벨은 학습에서 정답을 정의할 수 없으므로 추가하지 않는다.
- 기존 진단 90개는 문장 생성의 입력으로 읽지 않으며 학습/검증에 넣지 않는다. 정확히 같은 문장이 없는지 검사한다. 단, 유형 설명과 업무 어휘가 공통이고 의미상 유사성을 제거하지 못하므로 합성 데이터 과적합 가능성이 있다.
- 5 epochs, 검증 전체 경로 정확도가 가장 높은 시점을 선택하고 동률이면 NLL이 낮은 시점을 고른다. 기존 81개 단일 정답 시험 사례는 epoch 선택에 사용하지 않는다.
- mmBERT 인코더 동결, decision head만 soft-CE로 학습한다. head_lr 1e-4, micro_batch 4, grad_accum 4, 옵션 순서 shuffle, CPU FP32, seed 42, max_len 2048, head_max_len 1536.
- 선택 모델은 upstream 방식으로 FP16 저장하고 다시 로드한다. 저장된 모델로 기존 90개를 27개 일괄 방식과 예측 부모 기반 대→중→소 방식 모두 평가한다.
- 기본 모델과 학습 모델의 대분류, 대+중 경로, 전체 경로 정확도, 난이도별 성능, 첫 오류 단계, Macro F1, 지연, 입력/후보 잘림을 비교한다.
- 정보 부족 9개는 단일 정답 정확도에서 제외한다. 허용 경로 적중도는 참고치이며 재질문 능력 평가가 아니다.
- 이 실험은 작성자 생성 합성 자료의 단일 seed 실험이다. 실제 기관 데이터, 독립 라벨 검수, 다른 표현 분포, 카테고리 불균형과 drift를 검증하지 않는다.
